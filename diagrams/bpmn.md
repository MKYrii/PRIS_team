# Диаграммы бизнес-процессов (BPMN)

## AS-IS: Текущий процесс ручной модерации

```mermaid
flowchart TD
    A([Пользователь публикует\nкомментарий]) --> B[Комментарий\nопубликован]
    B --> C{Случайная\nвыборка?}
    C -- Нет ~90% --> Z1([Комментарий остаётся\nбез проверки])
    C -- Да ~10% --> D[Модератор читает\nкомментарий]
    D --> E{Нарушение?}
    E -- Нет --> Z2([Комментарий остаётся])
    E -- Да --> F[Модератор скрывает\nили удаляет]
    F --> G[Фиксация в журнале\nвручную]
    G --> H([Конец])

    R([Жалоба пользователя]) --> D2[Модератор читает\nпо жалобе]
    D2 --> E2{Нарушение?}
    E2 -- Нет --> Z3([Жалоба отклонена])
    E2 -- Да --> F2[Удаление/скрытие]
    F2 --> G

    style A fill:#dbeafe,stroke:#3b82f6,color:#000000
    style Z1 fill:#fef9c3,stroke:#eab308,color:#000000
    style R fill:#fee2e2,stroke:#ef4444,color:#000000
    style Z3 fill:#fef9c3,stroke:#eab308,color:#000000
```

### Проблемы AS-IS

| Проблема | Последствие |
|---|---|
| Проверяется только ~10% комментариев | 90% нарушений не обнаруживаются вовремя |
| Время реакции: часы | Токсичный контент висит часами |
| Субъективность модераторов | Непоследовательные решения → жалобы |
| Нет приоритизации | Срочные нарушения в очереди вместе с неактуальными |
| Нет аналитики | Невозможно отследить тренды токсичности |

## TO-BE: Процесс с ML-системой

```mermaid
flowchart TD
    A([Пользователь публикует\nкомментарий]) --> B[Comment Ingest Service]
    B --> K[(Kafka: topic\ncomments-raw)]
    K --> ML[ML Inference Service\nclassification + scoring]

    ML --> D{Score\nнарушения?}

    D -- score ≥ 0.85\nвысокая уверенность --> AUTO[Автоматическое скрытие\nModeration Action Service]
    D -- 0.40 ≤ score < 0.85\nнеопределённость --> QUEUE[Очередь для\nручной проверки]
    D -- score < 0.40\nнорма --> PUB([Комментарий\nопубликован])

    AUTO --> LOG[(Audit Log\nS3 + PostgreSQL)]
    AUTO --> NOTIFY[Уведомление\nпользователю]

    QUEUE --> MOD[Модератор\nпроверяет]
    MOD --> MD{Решение\nмодератора}
    MD -- Нарушение --> AUTO2[Скрыть/удалить]
    MD -- Норма --> PUB2([Комментарий\nостаётся])
    AUTO2 --> LOG
    MD --> FB[(Feedback Store:\nразметка для\nretrain)]

    ML --> ANALYTICS[(ClickHouse:\nаналитика)]
    ANALYTICS --> DASH[Dashboard:\nтренды тональности]

    FB --> RETRAIN[Weekly Retrain\nPipeline]
    RETRAIN --> MLREG[(MLflow\nModel Registry)]
    MLREG --> ML

    style A fill:#dbeafe,stroke:#3b82f6,color:#000000
    style AUTO fill:#dcfce7,stroke:#22c55e,color:#000000
    style ML fill:#ede9fe,stroke:#7c3aed,color:#000000
    style RETRAIN fill:#ede9fe,stroke:#7c3aed,color:#000000
    style DASH fill:#e0f2fe,stroke:#0284c7,color:#000000

```

### Что меняет ML-система

| Аспект | AS-IS | TO-BE |
|---|---|---|
| **Охват** | ~10% комментариев | 100% комментариев |
| **Скорость** | Часы | < 5 секунд |
| **Объём ручной работы** | 100% | ~10–15% (низкоуверенные) |
| **Последовательность** | Зависит от модератора | Единый воспроизводимый критерий |
| **Аналитика** | Отсутствует | Real-time дашборд |
| **Обучение** | Отсутствует | Автоматический retrain по фидбэку |
| **Аудит** | Ручной журнал | Полный автоматический лог |
